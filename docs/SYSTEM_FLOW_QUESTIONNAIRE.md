## 2. Evaluation Rating Scale

All evaluation statements are rated using the standard **5-Point Likert Scale**:

| Rating | Score | Description |
| :---: | :---: | :--- |
| **5** | **Strongly Agree (SA)** | Outstanding experience, completely satisfied and free of obstacles |
| **4** | **Agree (A)** | Good experience, meets expectations with minor or no friction |
| **3** | **Neutral (N)** | Average performance, neither satisfactory nor problematic |
| **2** | **Disagree (D)** | Unsatisfactory experience, causes confusion or operational friction |
| **1** | **Strongly Disagree (SD)** | Significant failure, unusable, or major system defect |
