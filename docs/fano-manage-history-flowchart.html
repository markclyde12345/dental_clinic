📜 Fano Dental Clinic – Manage History / Visits History Flowchart

Detailed Flowchart Specification Reference (Manage History Subsystem)

Step / Element Flowchart Symbol Codebase Route / File Detailed System Functionality & Logic
START Oval (Terminator) pages/admin-dashboard.html Entry point when administrator or clinic staff opens the system.
[ D ] Visits History Off-Page Connector / Shield #tab-history (Submodule [ D ]) Submodule connector branched from Master Admin Portal ([ AA ]).
Is user authenticated? Diamond (Decision) js/auth.js & JWT Verification Validates localStorage.token and role permissions. If expired, routes back via ( K1 ) to login.html.
Fetch Visits History Data Rectangle (Process) GET /api/appointments Calls REST API to retrieve historical appointments, clinical notes, patient details, and treatments.
DATABASE [ 2 ] Cylinder (Data Store) PostgreSQL / Supabase DB Data Stream [ 2 ] reading appointments, patients, treatments, clinical_notes, prescriptions.
Records Retrieved? Diamond (Decision) filterAndRenderHistory() Checks if data array contains valid visit records or network/permission error occurred.
Display Visits Ledger Parallelogram (I/O) #history-table-body Renders complete historical table: Appointment Date/Time, Patient, Procedure, Status, and Attending Dentist.
Search / Filter Action? Diamond (Decision) Filter Toolbar Evaluates whether user triggers keyword search or status dropdown filtering.
Filter by Keyword Rectangle (Process) #history-search-input Performs real-time string matching against patient names and dental treatment titles.
Filter by Status Rectangle (Process) #history-status-filter Filters rows by: Completed, Approved, Pending, Cancelled, or All.
Select Visit Record? Diamond (Decision) Row click / Details toggle Determines if user selects an individual consultation to view detailed clinical chart & diagnostic history.
Display Consultation Record Parallelogram (I/O) #modal-patient-history Presents patient medical conditions, allergy alerts, diagnosis notes, vital signs, and doctor notes.
History Follow-up Action? Diamond (Decision) Action Buttons Enables printing medical history slips or scheduling a follow-up consultation directly from historical logs.
Print History Summary Parallelogram (I/O) Print Utility / PDF export Generates a clean physical slip / patient visit summary report for documentation or insurance.
Book Follow-Up [ B ] Rectangle (Process) & Badge #btn-book-from-history → [ B ] Transfers patient data into Appointment Booking Wizard ([ B ] Manage Appointment).
Return / Exit Oval (Terminator) Admin Dashboard ([ AA ]) Closes history ledger and returns user to the main administrative portal or terminates session.
