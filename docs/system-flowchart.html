🔘 Flowchart Shapes & Notation

  • Oval: Terminator (System Start)
  • Rectangle: Process / System Web Page
  • Diamond: Decision Gateway (Yes / No)
  • Slanted Box: Submodule Input / Output Operations
  • Cylinder: Central Database (Supabase / PostgreSQL)

🔁 On-Page Loopback Connectors

  • ( K1 ): Circular connector looping back to Login page on failed validation.
  • ( K2 ): Circular connector looping back to Enter OTP on invalid one-time code.

🏷️ Off-Page Connectors & Badges

  • [ 1, 2, 3 ]: Data streams directly persisting to the central Database.
  • [ AA, BB, CC, I ]: Role Dashboard portals (Admin, Dentist, Staff, Patient).
  • [ A ] - [ G ]: Admin Management Submodules.
  • [ N ] - [ P ]: Dentist Clinical Submodules.
  • [ Q ] - [ S ]: Frontdesk Staff Submodules.
  • [ H ]: Universal Logout Action.
