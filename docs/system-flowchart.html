🔘 Flowchart Symbols

  • Oval: Terminator (Start / Stop)
  • Rectangle: System Page or Process
  • Diamond: Conditional Decision Branch
  • Slanted /: Module Input / Output Operations
  • Cylinder: Centralized Database (Supabase)

🔁 On-Page Reference Connectors

  • ( K1 ): Returns to Login Page on authentication failure.
  • ( K2 ): Returns to Enter OTP on invalid one-time passcode.

🏷️ Dashboard & Submodule Reference Badges

  • [AA], [BB], [CC]: Admin, Dentist, & Staff Dashboards
  • [A] to [G]: Admin Management Submodules
  • [I]: Patient Portal (Appointments, History, QR)
  • [N] to [P]: Clinical / Dentist Submodules
  • [Q] to [S]: Frontdesk Staff & Reception Submodules
  • [H]: Unified System Logout & Session Destroy
