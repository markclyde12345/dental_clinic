🔘 Flowchart Symbols

  • Oval: Terminator (System Start / Session Destroy)
  • Rectangle: Web Page or Application Module
  • Diamond: Role Check or Conditional Decision Branch
  • Purple Border: AI Dental Assistant Subsystem
  • Green Cylinder: Centralized Database (PostgreSQL / Supabase)

🔁 On-Page Reference Connectors

  • ( K1 ): Returns to Universal Login Page upon invalid credentials.
  • ( K2 ): Returns to Verify OTP upon incorrect two-factor code.

  • [AA]: Administrator Portal (System management, RBAC, Inventory)
  • [I]: Patient Portal (Appointments, Prescriptions, 2FA Settings, AI Chat)
  • [BB]: Dentist Clinical Portal (Odontogram charting, Treatment plans)
  • [CC]: Receptionist Portal (Queue management, Cashier, Registration)
